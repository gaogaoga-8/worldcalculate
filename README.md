# 世界算法

本地优先的中文命理应用。从出生时刻与城市开始，进入属于自己的星系，与本命星对话，在每天的交流中逐渐点亮其他星。

个人星系采用深空底色、银白星光与留白。星星之间不画连线。

## 当前体验

1. **两步选择。** 入口只保留出生时刻和出生地。公历年、月、日与 24 小时制的时、分均为选择器，也可选择时间不详。地点依次选择国家 → 省份 / 自治区 / 直辖市 → 城市 / 地区，再选择计算所需的性别。年月切换清除无效日期，地区切换清除下级选择。
2. **连续的群星动画。** 众多细小星光从舒展的星尘中缓缓散开，一颗星沿弧线停在本命位置，约 7.6 秒后开放交互。动画与主屏共用同一个画布和本命星对象，结束时保留位置、亮度和运动；跳过也会平滑收尾。支持减少动态效果设置，切到后台暂停动画。
3. **点击星星。** 主屏只保留星空、本命星、七颗暗星与小小的世界入口。点击已点亮的星展开内容；桌面为侧边浮层，手机为底部面板。对话、命盘、人格和问事只在展开后出现。对话向模型传递最近十二条消息作为上下文。
4. **每天最多一颗。** 按北京时间日历日计算。当天完成两次成功的对话后，回到星空，直接点击下一颗微微发光的星点亮它。本命星不占每日额度。当天再次对话不解锁第二颗；次日需要完成当天的两次对话。最多点亮七颗轮次星。刷新后保留点亮时间、每日限制和记录。
5. **人格与记录。** 人格测试在星星内容中，可选、可继续或重做。点亮后的星位置固定，展开「星星里的话」可留下自己的那句话。
6. **命盘与问事。** 星星面板内切换内容。问一件事需一颗有完整记录的星，问感情需三颗，问关系需已连接的朋友；条件不足时保留原有本地限制。
7. **世界与连接。** 主屏左下方的小行星进入原来的地球与好友功能，星系预览使用相同动画。星系卡前缀仍是 `SJ1.`。
8. **保留已有数据。** 已有星星、对话、好友与计划不删除；重新录入出生信息保留对话和星星。人格结果随本机记录保存。模型密钥不进入星图导出。菜单「重新开始」先保存可恢复的上一次记录；也支持 `?restart=1` 链接，处理后自动移除参数。

## 城市数据

`src/data/china-cities.json` 是轻量离线数据，包含中国大陆 31 个省级地区和 367 个城市 / 地区选项，包括自治州、地区与部分省直辖县市。北京、天津、上海、重庆选择同名城市。国家第一阶段只开放中国，范围为大陆。

名称、行政区代码和中心坐标来自 [阿里云 DataV GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector)。2026-10-07 下载后仅保留所需字段，不含地图几何数据（约 32 KB），使用选择器无需联网。命盘计算使用城市中心坐标，不是具体医院或街道的坐标。

`src/knowledge/pack.ts` 保持空，不编造紫微飞星规则。

## 本地怎么跑

需要 Node。依赖从 `https://registry.npmmirror.com` 安装。

```bash
npm install
npm run dev
```

开发地址默认是 `http://127.0.0.1:5173/`，占用时 Vite 选择下一个端口。`npm run build` 先做类型检查再打包，`npm run check` 跑八字自检，`npm run check:experience` 检查每日点亮、跨天、生日合法性与省市级联，`npm run check:render` 检查服务端渲染结构与对话上下文，`npm run check:cosmos` 检查散开轨迹与动画收尾连续性。

记录在浏览器 `localStorage`，键是 `shijie-suanfa/v1`。模型地址、模型名和密钥在另一个键 `shijie-suanfa/model`，星图导出不含密钥。

八字在浏览器里算：立春换年、节气换月、真太阳时，默认早子时，中国民用时 UTC+8。自检盘：2000-01-01 12:00 北京、男、早子时，应得己卯 丙子 戊午 戊午。

## 模型接口

菜单里可以填自己的接口地址、模型名和密钥。三项都空着时，开发服务器用本机的 Cursor 密钥（只读环境变量 `CURSOR_API_KEY`，放在 `.env.local`）。三项都填满时，请求经本机 `/api/oracle` 转发。

手机安装包里没有开发服务器。手机上三项都必须填，应用直接请求对方自己的接口。Cursor 的密钥不能放进安装包，也不能放进交给别人的源码。

## 交给别人的手机

本轮改动已构建并同步到 `android/app/src/main/assets/public`。已有 APK 不会自动更新，本次没有重新生成 APK；安装包需要使用 Android 工具链重新打包。

桌面上的 `世界算法.apk` 是安卓调试包，手机上允许安装未知应用后即可打开。苹果手机不能装这个文件。

安卓工程不在这份源码的常规目录里。本机因为中文路径会让 Gradle 失败，工程放在 `C:\Users\gb\AppData\Local\shijie-apk`。代码包里的 `android/` 是去掉构建缓存后的副本。要重新打包，把整个项目放在英文路径下，先 `npm run build`，再同步到 Capacitor 后执行 `gradlew assembleDebug`。

## 目录

- `src/App.tsx`：写入、星系动画、首页与自我的切换
- `src/components/IntakeChat.tsx`、`src/components/BirthFields.tsx`：出生信息选择器
- `src/components/Nebula.tsx`、`src/cosmos.ts`：连续星空、星尘散开和本命星轨迹
- `src/data/china-cities.json`：离线省市数据
- `src/galaxy.ts`：点星、有形体、星系卡 `SJ1.`
- `src/components/SelfSky.tsx`：星系、命盘、可选人格探索与三问
- `src/components/ConnectMap.tsx`：地球、罗列、交换卡
- `src/bazi/`：真太阳时、四柱、十神、大运
- `src/oracle/`：主控提示词、微调、浏览器侧请求
- `server/oraclePlugin.ts`：仅开发服务器上的 `/api/oracle`
- `src/knowledge/pack.ts`：空的知识包

虚拟测试用户的 id 以 `virt-` 开头。没有人要求清除时，不要删掉已有记录，也不要重新种一遍，否则会重复。

更早的决定和取舍见 `对话浓缩.md`。
