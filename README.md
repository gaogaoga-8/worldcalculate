# 世界算法

从三颗星开始：生日、来处、名字。点开一颗，填完一颗；三颗星汇成星系，星尘逐个浮现、向外舒展，生日星停在本命的位置。动画与主屏使用同一个画布和同一颗可点击的本命星，约 7.6 秒收尾。支持平滑跳过、后台暂停和减少动态效果。

这一版先只提供访客体验。动画结束后出现轻量入场引导，账号绑定留待后续接入。

## 体验

- 入口没有整页表单或长说明。生日精确到分钟，可选时间不详；地区依次选择国家 → 省级地区 → 城市，目前开放中国大陆；名字支持昵称。性别放在名字星里，供原有命盘计算使用。
- 主屏以星星为入口：一颗本命星、七颗暗星、一个「远方」。点击星星才展开对话、命盘、可选人格测试和问事。桌面使用侧边浮层，手机使用底部面板。
- 聊天保留最近 24 条消息与用户自己写下的星星记录。先回应具体经历、情绪与需求，命盘只在用户明确问起时作为传统解读背景；不编造命运、他人的动机或关系结果。实际回复来自配置的模型，没有内置假回复。
- 每天完成两次成功的对话后，下一颗星轻轻呼吸；点亮时先出现光晕，再打开当天的小问题。七颗星分别围绕休息、被看见、勇气、同行、边界、感谢和愿望。按北京时间每天最多点亮一颗，失败请求不计数，次日需要当天的新对话。
- 写在星星里的话默认只保存在本机。选择「送到远方」后仍需主动确认发布；只公开称呼与这句回声。远方优先展示互补的意愿与相近话题，如「想被听见」与「愿意听你说」。没有人发布时显示空星空，没有预设或虚构用户。
- 回应另一位访客会送出一次邀请。对方选择「愿意聊聊」后才能继续私聊，也可以略过。双方在星空中点击对方的星继续对话；支持收回公开回声、屏蔽另一颗星。发现列表每 20 秒刷新，打开的对话每 5 秒刷新。
- 原有星图卡、好友记录与星图导入 / 导出保留在菜单中。重新录入不删除星星和聊天；本机清空先保存可恢复备份。个人星系与模型配置保持分开，导出不包含密钥。

## 运行

需要 **Node.js 24**（使用内置 `node:sqlite`）。

```bash
npm ci
cp .env.example .env
npm run dev
```

`.env` 中可以配置服务端模型；不配置模型时仍可填写星系、记录和使用回声，聊天会明确提示尚未连接。密钥不要提交到 Git。

```dotenv
ORACLE_BASE_URL=https://your-provider.example/v1
ORACLE_MODEL=your-model-name
ORACLE_API_KEY=your-secret
```

模型接口需兼容 `POST /chat/completions`。仅在本机开发时，也支持菜单里的自带接口，或环境变量 `CURSOR_API_KEY`。正式服务拒绝浏览器指定任意转发目标，只使用服务端配置。客户端配置不参与导出。

正式运行需要同时提供页面、聊天 API 和社交 API：

```bash
npm run build
npm start
```

默认监听 `127.0.0.1:5175`。上线时通过 HTTPS 反向代理，设置 `APP_ORIGIN` 为完整公网源地址（如 `https://example.com`）以及 `COOKIE_SECURE=1`；可通过 `HOST`、`PORT` 调整监听。不要只部署 `dist` 到静态站点，否则真实访客社交和服务端聊天无法工作。

## 记录与边界

- 个人出生信息、命盘、人格测试和与 AI 的聊天仍保存在当前浏览器的 `shijie-suanfa/v1`。发给聊天模型的上下文包含称呼、四柱与用户写下的记录，不包含精确出生日期或城市。
- 访客身份使用 HttpOnly、SameSite cookie，服务端只保存会话凭据的哈希。清除 cookie 或换浏览器后目前不能找回原访客身份；账号接入后再提供绑定与跨设备恢复。
- 公开回声、双方确认与彼此的私聊使用 SQLite，默认文件 `.data/community.sqlite`，重启后保留。线上必须设置 `COMMUNITY_DB` 指向持久化磁盘，并备份数据库；不要使用临时容器磁盘。单机服务实现，没有做分布式消息推送。
- 公开回声在发现列表保留七天，每人每天一条，可修改和收回。不会自动公开出生地点、生日、人格、AI 对话或私人星星记录。私聊读取和发送由服务端检查成员身份与双方同意，屏蔽后禁止继续发送。
- 目前是访客互相发现的可运行版本，尚未提供账号、密码、跨设备同步、举报审核后台或推送通知。面向公众发布前需接入这些运营能力。
- 本轮更新面向网页。仓库中已有 Android 资源与 APK 是旧产物，没有宣称新版 APK 已生成。新的社交功能依赖同源服务端；原生包需要另行配置服务地址与会话方案再打包，不能直接把静态页面复制进 APK 就使用社交。

## 检查

```bash
npm run build
npm run check
npm run check:experience
npm run check:render
npm run check:cosmos
npm run check:reset
npm run check:community
```

涵盖类型检查、八字自检、跨天与每日额度、日期和省市级联、三颗入口星、动画最后一帧连续性、记录恢复，以及隔离数据库上的真实访客发现、邀请、双方同意、私聊授权、持久化、收回、屏蔽和跨源请求限制。模型转发检查使用独立测试接口，不能作为真实模型的情绪回应质量评测。

## 主要代码

- `src/components/IntakeChat.tsx`、`BirthFields.tsx`：三颗入口星与渐进选择器
- `src/components/Nebula.tsx`、`src/cosmos.ts`：星系形成、散开与同一颗本命星
- `src/components/Arrival.tsx`：动画结束后的访客入场
- `src/components/SelfSky.tsx`、`src/ritual.ts`：点击星星、每日问题、私人记录
- `src/components/SocialSky.tsx`、`src/community.ts`：真实回声、双方确认与私聊
- `src/oracle/`：自然对话上下文与模型请求
- `server/community.ts`：SQLite 访客、回声、私聊与权限
- `server/oraclePlugin.ts`、`server/index.ts`：开发 / 正式服务

## 城市与命盘

`src/data/china-cities.json` 为离线数据，含中国大陆 31 个省级地区、367 个城市 / 地区选项，约 32 KB。名称、代码和城市中心坐标来自 [DataV GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector)，保留 2026-10-07 下载版本。使用城市中心坐标，不代表医院或街道位置。

八字在浏览器计算：立春换年、节气换月、真太阳时，中国民用时 UTC+8，默认早子时。`src/knowledge/pack.ts` 保持空，不编造紫微飞星规则。
